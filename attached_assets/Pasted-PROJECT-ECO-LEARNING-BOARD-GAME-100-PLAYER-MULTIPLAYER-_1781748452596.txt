PROJECT: ECO LEARNING BOARD GAME (100+ PLAYER MULTIPLAYER)

IMPORTANT: THIS IS NOT A QUIZ APP WITH ICONS. THIS IS A REAL GAME.

VISUAL DESIGN GOAL

Create a polished educational multiplayer board game that feels like a professional 2D adventure game.

Do NOT use:

* Emojis
* Unicode symbols
* Animal emojis
* Hazard emojis
* Colored circles as players
* Placeholder icons
* Font Awesome icons for animals
* Static symbols
* Text representations of animals

Every animal, hazard, and board object must be represented using actual sprite graphics and animations.

=================================================================
CHARACTER MOVEMENT SYSTEM
=========================

Animals must behave like real game characters.

When a player moves:

DO NOT:

* Teleport the animal
* Instantly jump to destination tile
* Change only the position number

INSTEAD:

1. Start movement animation
2. Move smoothly along the board path
3. Travel tile by tile
4. Arrive at destination
5. Return to idle animation

Examples:

Tiger:

* Runs between tiles
* Tail and legs animated

Rabbit:

* Hops between tiles

Turtle:

* Slow walking animation

Snake:

* Slithering animation

Eagle:

* Wing flap animation
* Glides between positions

Dolphin:

* Swimming animation
* Water leap animation

Animals should feel alive while standing still:

* Blink
* Tail movement
* Breathing
* Idle motions

=================================================================
HAZARD SYSTEM
=============

Hazards are not icons.

Hazards are animated entities.

Examples:

Eagle Attack:

* Eagle enters screen
* Eagle flies toward target
* Attack animation
* Target reacts

Wolf Attack:

* Wolf runs toward target
* Bite animation
* Animal reaction

Pollution:

* Smoke spreads
* Plastic drifts
* Water darkens

Poaching:

* Trap appears
* Warning animation
* Capture effect

Wildfire:

* Fire spreads
* Smoke rises
* Emergency effect

Each hazard must have:

Entrance Animation
Action Animation
Exit Animation

=================================================================
CUTSCENE SYSTEM
===============

When hazards occur:

Pause board movement.

Play short cinematic sequence.

Example:

Rabbit lands on eagle tile.

Sequence:

Eagle appears.
Eagle dives.
Rabbit reacts.
Penalty applied.
Game resumes.

Keep cutscenes short:
2–4 seconds.

AUDIO SYSTEM
============

REMOVE ALL ANNOYING BUZZER SOUNDS.

DO NOT USE:

* Loud incorrect buzzers
* Harsh alarms
* Game-show sounds
* Aggressive warning tones
* Stress-inducing sounds

The game should feel calm and educational.

CORRECT ANSWER:

Use:

* Soft chime
* Gentle nature bell
* Pleasant success tone

WRONG ANSWER:

Use:

* Soft wooden click
* Gentle muted tone
* Light natural sound

NO BUZZER.

NO LOUD ERROR SOUND.

BACKGROUND MUSIC:

Forest:

* Birds
* Wind
* Gentle ambience

Water:

* Flowing water
* Soft ambient music

Desert:

* Calm wind
* Atmospheric tones

Human Impact:

* Slightly serious ambience
* Not stressful

Restoration:

* Inspiring relaxing music
* Nature sounds

Volume should remain comfortable.

Audio should reduce stress, not create stress.
